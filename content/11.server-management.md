This section is still a draft. Community notes pointed at **game panels, scripts, and SSH**, from a basic `.bat` / `.sh` start script all the way up to a full panel.

Options that came up in the FAQ comments:

- [Pterodactyl](https://pterodactyl.io/)
- [Multicraft](https://www.multicraft.org/)
- [LinuxGSM](https://linuxgsm.com/) (LGSM)
- Tmux / Screen
- [PufferPanel](https://pufferpanel.com/)
- [AMP](https://cubecoders.com/AMP)
- [Wisp](https://wisp.gg/)
- [Crafty Controller](https://craftycontrol.com/)

Ask on [Discord](https://discord.gg/Dx6SSkx) if you need help picking one for your setup.
